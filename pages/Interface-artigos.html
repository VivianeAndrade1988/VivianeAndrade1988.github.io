A empresa tinha milhões de dados… mas tomou uma decisão errada

01. O problema: quando muitos dados não significam boas decisões

Imagine uma empresa chamada NovaMarket, uma rede varejista com:

  • 250 lojas;
  • 5 milhões de clientes cadastrados;
  • milhões de transações realizadas todos os meses.

A empresa investiu nos últimos anos em tecnologia. Agora possui ERP, CRM, aplicativo próprio, programa de fidelidade e diversos dashboards.

A diretoria acredita que possui tudo que precisa para crescer.

Porém, nos últimos meses surgiu uma oportunidade.

Indicador Resultado
Receita anual +15%
Clientes cadastrados +20%
Número de pedidos +12%

O diretor comercial conclui:

"Estamos crescendo. Precisamos abrir novas lojas imediatamente."

O plano aprovado previa:

  • investimento de R$ 30 milhões;
  • abertura de 20 novas unidades;
  • contratação de 500 funcionários.

Antes da execução, a diretoria chama um Analista de Dados e faz uma pergunta simples:


"Esse crescimento realmente representa uma melhora geral da empresa?"

02. O papel do Analista de Dados

Um erro comum nas empresas é acreditar que:

Mais dados = melhores decisões.

Mas isso não é necessariamente verdade.

Dados sem análise podem gerar interpretações equivocadas.

O papel do analista é transformar:

Dados
→
Informação
→
Insight
→
Decisão

Antes de responder: "Devemos abrir novas lojas?", o analista precisa investigar:

  • Todas as lojas cresceram?
  • O crescimento aconteceu em todas as regiões?
  • Alguns produtos estão puxando o resultado?
  • Existem lojas com queda?
  • O crescimento é sustentável?

É aqui que entra a Estatística.

03. O que é Estatística?

Estatística é a ciência responsável por coletar, organizar, analisar e interpretar dados para identificar padrões e apoiar decisões.

Dentro das empresas, ela pode ajudar a responder:

Comercial: Qual vendedor realmente performa melhor?

Marketing: A campanha aumentou as vendas ou foi apenas coincidência?

Supply Chain: Qual fornecedor apresenta melhor desempenho?

Financeiro: Esse investimento trouxe retorno?

Recursos Humanos: Existe diferença salarial entre áreas?

04. Os dois grandes caminhos da Estatística

De forma simplificada, podemos pensar em dois grandes grupos:

Estatística Descritiva

"O que aconteceu?"

Seu objetivo é resumir e organizar os dados existentes.

  • faturamento médio;
  • produto mais vendido;
  • região com maior venda;
  • taxa de cancelamento;
  • desempenho dos vendedores.

Estatística Inferencial

"O que podemos concluir?"

Utiliza dados de uma amostra para tirar conclusões sobre uma população maior, sempre considerando a incerteza.

  • pesquisas por amostragem;
  • intervalos de confiança;
  • testes de hipóteses;
  • estimativas;
  • modelos estatísticos.

Um exemplo simples

A NovaMarket analisa as vendas do último ano e encontra:

Região Crescimento
Sudeste +25%
Sul +18%
Nordeste +3%
Norte -8%
Insight

A média escondia um problema.

O crescimento não aconteceu de maneira uniforme. Algumas regiões cresceram muito, enquanto outra apresentou queda.

05. Voltando ao caso da NovaMarket

O analista começou utilizando Estatística Descritiva para entender a distribuição do faturamento entre as lojas.

Faturamento por loja

Loja Faturamento
Loja A R$ 500 mil
Loja B R$ 520 mil
Loja C R$ 510 mil
Loja D R$ 2 milhões

A diretoria estava olhando apenas para o crescimento total.

Porém, quando o analista abriu os dados por unidade, encontrou algo importante:

Uma única loja apresentava desempenho muito acima das demais.


O crescimento não era necessariamente generalizado.

Pergunta de negócio

O que estava fazendo essa loja performar tão acima das outras?

Antes de replicar o modelo em 20 novas unidades, era necessário entender se aquele resultado poderia ser reproduzido.

06. Como um Analista de Dados faria essa análise?

A análise poderia combinar diferentes ferramentas. Cada uma cumpre um papel dentro do processo.

SQL — extração e organização

Exemplo: 

SELECT
    loja,
    SUM(valor_venda) AS faturamento
FROM vendas
GROUP BY loja
ORDER BY faturamento DESC;

O objetivo dessa consulta é identificar quais lojas geram maior faturamento.

Python — exploração dos dados

Em Python, bibliotecas como Pandas, NumPy e Matplotlib podem ser utilizadas para explorar os dados. 

df.groupby("loja")["venda"].sum()

A análise pode evoluir para distribuição, medidas de tendência central, variabilidade, correlação e outras técnicas estatísticas.

Power BI — comunicação da análise

Depois de explorar os dados, o analista pode transformar os principais achados em uma visão executiva.

  • faturamento por loja;
  • crescimento mensal;
  • ranking de unidades;
  • comparação regional;
  • evolução dos indicadores.

A ferramenta não é o objetivo.


SQL ajuda a consultar. Python ajuda a explorar. Power BI ajuda a comunicar. A análise é o que conecta tudo isso à decisão de negócio.

07. O erro que a Estatística evitou

Sem uma análise mais detalhada, a empresa poderia abrir 20 novas lojas com base em uma interpretação equivocada do crescimento.

Entre as possíveis consequências:

  • aumento de custos;
  • lojas abaixo da meta;
  • excesso de capacidade;
  • retorno financeiro menor que o esperado;
  • capital investido em unidades pouco rentáveis.

Com a análise, a empresa decidiu seguir outro caminho:

  1. investigar a loja de maior desempenho;
  2. identificar as práticas que explicavam seu resultado;
  3. avaliar se essas práticas poderiam ser replicadas;
  4. testar a expansão antes de realizar um investimento maior.
Decisão

Antes de escalar um resultado, precisamos entender sua causa.

Um bom resultado não significa necessariamente que o mesmo padrão se repetirá em outro contexto.

08. Principais aprendizados

01. Dados não são respostas.

São evidências que precisam ser interpretadas dentro de um contexto.

02. Um número isolado pode enganar.

Sempre precisamos investigar distribuição, comparação, tendência e contexto.

03. Estatística reduz decisões baseadas apenas em opinião.

Ela permite estruturar evidências e quantificar comportamentos e incertezas.

04. O papel do analista não é apenas criar gráficos.

É transformar perguntas de negócio em análises capazes de apoiar decisões.

O objetivo final da análise não é produzir um número. É ajudar alguém a tomar uma decisão melhor.

Quer entender a matemática por trás?

A Estatística começa a ficar interessante quando entendemos o que existe por trás dos indicadores.

Nos próximos artigos vamos sair da visão conceitual e começar a calcular e interpretar medidas estatísticas aplicadas a problemas de negócio.

Vamos começar por:

  • Média;
  • Mediana;
  • Moda;
  • e depois avançar para medidas de dispersão, como variância e desvio padrão.
Exercício para o leitor

Uma empresa informa: "Nosso faturamento cresceu 20% este ano."

Antes de comemorar, quais perguntas você faria?

  • O crescimento aconteceu em todas as regiões?
  • Quantos clientes novos vieram?
  • O ticket médio aumentou?
  • Quais produtos geraram o crescimento?
  • O lucro também aumentou?
  • O crescimento foi consistente ao longo do ano?

A resposta não está necessariamente no crescimento de 20%. Ela está nas perguntas que fazemos depois dele.
